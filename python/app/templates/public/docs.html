Overview

AeroRoute AI is an academic aviation operations-intelligence and route-optimization decision-support prototype. It models a small airport network as a weighted directed graph, computes paths with custom Dijkstra and A* search, and estimates delay categories with a deterministic scoring demonstration.

The console exposes each stage as a dedicated module backed by a REST endpoint, so every recommendation can be traced back to its inputs.

Algorithms & Cost Model

The router optimizes edge cost over the graph, where each component is normalized before weighting: 

C(e) = w_d·(D/2500) + w_t·(T/300) + w_w·(W/100) + w_c·(C/100) + w_r·R
  • Dijkstra Exhaustive min-priority search yielding a mathematically optimal cost.
  • A* Admissible Haversine great-circle heuristic producing identical optimal paths with substantially fewer explored nodes.

Limitations & Safety

This is not certified aviation software. It holds no ATC authority, flight-dispatch clearance or avionics guarantees, and must never be used for real dispatch or navigation. Congestion telemetry is derived mathematically, weather is limited to METAR observations, and the prediction endpoint uses deterministic scoring rather than a loaded trained model.
